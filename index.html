Algoritmo de Floyd–Warshall — Visualização Interativa

Ideia Principal

A ideia central do algoritmo é verificar, para cada par (i, j), se existe um caminho via k que seja mais barato. O teste é:

if (d[i][k] < INF && d[k][j] < INF)
    d[i][j] = min(d[i][j], d[i][k] + d[k][j]);

Ou seja: só somamos d[i][k] + d[k][j] se ambos forem válidos.

Como calcular o menor caminho passando por até k vértices?

Limite o loop externo: 


      n = vertices;
for (int inter = 0; inter < k; inter++) { // limite o loop externo
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            d[i][j] = min(d[i][j], d[i][inter] + d[inter][j]);
        }
    }
}

É possível adaptar o algoritmo para calcular o caminho que minimiza o peso da maior aresta?

Sim, substitua a operação soma por "máximo", e min por "minimização do maior custo". 


// Floyd-Warshall para caminho minimax
for (int k = 1; k <= n; k++) {
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            d[i][j] = min(
                d[i][j],
                max(d[i][k], d[k][j]) // custo = maior aresta do caminho
            );
        }
    }
}

Isso calcula o caminho onde o "custo" de um caminho é definido como a maior aresta contida nele, e buscamos minimizar esse valor.
